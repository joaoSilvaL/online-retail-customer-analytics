# Online Retail II – Análise de Dados e Segmentação de Clientes

## Sobre o projeto

Projeto de Ciência de Dados desenvolvido a partir do dataset Online Retail II, com o objetivo de explorar dados transacionais de um e-commerce e investigar padrões de comportamento dos clientes.

O projeto utiliza SQL e Python para estruturar, tratar e analisar os dados, buscando transformar registros de vendas em informações relevantes para o entendimento do negócio.

## Objetivos

- Explorar e compreender os dados transacionais.
- Investigar o comportamento de compra dos clientes.
- Construir indicadores relacionados a vendas e clientes.
- Aplicar técnicas de engenharia de atributos (Feature Engineering).
- Desenvolver uma base para análise e segmentação de clientes.

## Dataset

O projeto utiliza o dataset [Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii), disponibilizado pelo UCI Machine Learning Repository.

O conjunto de dados contém aproximadamente 1 milhão de registros de transações de um varejista online britânico, abrangendo o período de dezembro de 2009 a dezembro de 2011.

Entre as principais informações disponíveis estão:
- Identificação de faturas e produtos.
- Quantidade de itens vendidos.
- Data das transações.
- Preços dos produtos.
- Identificação dos clientes.
- País de origem dos clientes.

## Metodologia

O desenvolvimento segue etapas de um fluxo de análise de dados:

1. **Entendimento do negócio:** identificação dos objetivos e das questões que orientam a análise.
2. **Exploração dos dados:** investigação das características, distribuição e qualidade dos dados.
3. **Preparação dos dados:** tratamento de inconsistências e organização das informações utilizando SQL e Python.
4. **Engenharia de atributos:** construção de variáveis relevantes para análise do comportamento dos clientes.
5. **Análise e segmentação:** exploração de indicadores e aplicação de técnicas de segmentação de clientes.
